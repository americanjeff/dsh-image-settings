# ![dsh-image-settings icon](assets/icons/image-settings-icon.png) dsh-image-settings

English | [中文](README.zh.md)

Shows `read_image` results inline in dsh web sessions — at the row's available width, auto-unrolled — with the display tunable live from the Image settings card.

## Install

```
dsh plugin --profile web add dsh-image-settings
```

(restart `dsh web` once after first install)

## Configuration

![](e2e-card-clean-dark.png)

The card's fields map 1:1 to the `image-settings:` section of `settings.yaml`.
